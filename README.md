# 📖 Sobre o Projeto

O **Conta Comigo** é um aplicativo de organização financeira baseado em conversas naturais.

A proposta surgiu a partir da seguinte reflexão:

> Muitas pessoas abandonam aplicativos financeiros porque precisam preencher formulários, configurar categorias e registrar dados manualmente.

Pensando nisso, foi criado um assistente financeiro capaz de receber informações por texto ou voz, interpretando comandos simples como:

```text
"Gastei R$ 40 no mercado."
"Recebi R$ 500 hoje."
"Quanto gastei este mês?"
"Como estão minhas metas?"
```

O sistema transforma essas conversas em registros financeiros e apresenta informações relevantes de forma simples e acessível.

# PRD – Assistente Financeiro Conversacional

## 1. Visão Geral

Desenvolver um aplicativo de organização financeira que funcione principalmente por meio de conversas em linguagem natural.

O usuário poderá registrar receitas, despesas, consultar saldos, criar metas e receber orientações financeiras utilizando texto ou voz, da mesma forma que conversa com uma pessoa.

O produto deve priorizar simplicidade, acessibilidade e inclusão, permitindo que pessoas com diferentes níveis de conhecimento tecnológico administrem suas finanças sem depender de planilhas ou sistemas complexos.

---

# 2. Problema

Muitas pessoas abandonam aplicativos financeiros porque:

- Exigem muitos formulários.
- Possuem excesso de funcionalidades.
- Utilizam linguagem técnica.
- Não são intuitivos para iniciantes.
- Não atendem bem idosos ou pessoas com baixa familiaridade digital.

O resultado é a falta de controle financeiro e dificuldade para atingir objetivos financeiros.

---

# 3. Proposta de Valor

Transformar o controle financeiro em uma conversa simples e natural.

Em vez de navegar por menus complexos, o usuário pode dizer:

"Gastei R$ 30 com almoço."

ou

"Recebi R$ 1.500 hoje."

O sistema interpreta, registra, organiza e apresenta informações relevantes automaticamente.

# 6. Funcionalidades do MVP

## 6.1 Chat Financeiro

Funcionalidade principal da aplicação.

Exemplos:

- "Gastei R$ 45 no mercado."
- "Recebi R$ 2.000 de um cliente."
- "Quanto gastei este mês?"
- "Como está minha meta?"

O sistema deverá:

- Interpretar a mensagem.
- Identificar intenção.
- Registrar ou consultar informações.
- Confirmar a ação realizada.

---

## 6.2 Registro Automático

O sistema deverá identificar:

- Receita ou despesa.
- Valor informado.
- Data.
- Categoria.

Categorias iniciais:

- Alimentação
- Transporte
- Moradia
- Saúde
- Educação
- Lazer
- Trabalho
- Outros

---

## 6.3 Metas Financeiras

Permitir criação e acompanhamento de objetivos financeiros.

Exemplos:

- Reserva de emergência.
- Viagem.
- Compra de equipamento.
- Quitação de dívidas.

O sistema exibirá:

- Valor da meta.
- Valor acumulado.
- Percentual concluído.
- Previsão de conclusão.

---

## 6.4 Assistente Financeiro

Agente conversacional responsável por orientar os usuários.

Exemplos:

- Alertar aumento de gastos.
- Sugerir economia.
- Incentivar hábitos saudáveis.
- Explicar conceitos financeiros em linguagem simples.

O tom deve ser sempre educativo, acolhedor e não julgador.

---

## 6.5 Dashboard Simplificado

Apresentar apenas informações essenciais.

Indicadores:

- Saldo atual.
- Receitas do período.
- Despesas do período.
- Progresso das metas.

Visualizações:

- Cartões-resumo.
- Gráfico de categorias.
- Evolução mensal básica.

# 7. Fluxos Principais

## Primeiro Acesso

1. Criar conta.
2. Selecionar perfil.
3. Informar objetivo financeiro principal.
4. Receber breve apresentação do aplicativo.
5. Iniciar utilização.

Tempo esperado: menos de 3 minutos.

---

## Registro de Transação

1. Usuário envia texto ou áudio.
2. Sistema interpreta a intenção.
3. Exibe confirmação.
4. Registro é salvo.
5. Dashboard é atualizado.

---

## Consulta Financeira

1. Usuário faz uma pergunta.
2. Sistema interpreta a solicitação.
3. Responde em linguagem simples.
4. Permite aprofundar caso desejado.

---

## Meta Financeira

1. Usuário cria objetivo.
2. Define valor desejado.
3. Sistema calcula progresso.
4. Exibe acompanhamento contínuo.

- A interface deve ser autoexplicativa.

# 10. Critérios de Sucesso

O MVP será considerado bem-sucedido se:

- O usuário conseguir registrar uma transação em menos de 10 segundos.
- O primeiro registro ocorrer sem necessidade de tutorial.
- Pelo menos 80% das classificações automáticas estiverem corretas.
- O usuário conseguir consultar saldo e metas de forma independente.
- Idosos e usuários com baixa experiência tecnológica conseguirem utilizar a aplicação sem auxílio externo.
- Usuários com necessidades de acessibilidade conseguirem utilizar as funcionalidades essenciais do produto.

Os créditos gratuitos do Lovable se esgotaram antes desses ajustes.

Esses refinamentos ficarão para uma próxima versão.

# 📚 O Que Aprendi Sobre Conversar com IAs

Este projeto mostrou que a qualidade da solução está diretamente relacionada à qualidade do contexto fornecido.

Principais aprendizados:

- Bons prompts começam pela definição clara do problema.
- Explicar as dores do usuário gera melhores resultados.
- Definir o público-alvo muda completamente a qualidade das respostas.
- Refinar prompts é parte fundamental do processo.
- IA não substitui o raciocínio humano, mas amplia sua capacidade de execução.

Também aprendi que um copiloto de IA pode ajudar a resolver problemas complexos trazendo simplicidade para a construção de produtos.

Com Vibe Coding é possível:

- Validar ideias rapidamente.
- Criar MVPs em tempo recorde.
- Economizar tempo de desenvolvimento.
- Explorar múltiplas soluções.
- Focar na experiência do usuário.
